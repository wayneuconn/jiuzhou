# Release Notes

## v1.2.0 — 2026-07-29

### 微信通知全面上线
- **管理员**：有人请假/退出（含当前人数与候补数）、报名满员、会员申请，直达微信服务通知
- **年卡**：新比赛开放 R1 报名时收到通知（手动开放和每周自动建赛都触发）
- **次卡**：R2 全员报名开放时收到通知（已报名/候补中的不打扰）
- **带朋友**：朋友递补进名单时通知带人者，并提醒咨询管理员缴费
- 通知额度自动积攒：球员在报名/候补/确认时授权（勾"总是保持"后无感），管理员在后台操作时积攒。首次会弹一次授权框

### 队长权限
- **开始选人**：两名队长设置好后，队长可直接在比赛页点「🚀 开始选人」，不用等管理员
- **审核捞人**：候补列表的「↑ 进名单」按钮对本场队长开放

### 散客管理（会员门槛 + 代报）
- 未开通会员的新人不能自行报名，比赛页显示引导卡（联系管理员缴费 → 申请次卡 → 批准后可报名）
- **管理员代报名**：名单标题旁「+ 代报名」打开成员选择器（可搜索），不限数量；有空位直接进名单，满员按优先级入候补
- 管理员可移除名单/候补中的**任何人**，空位自动递补

### 比赛日 14:00 截止规则
- 第 23 位报名时弹警告：若 14:00 前未满 24 人将转为候补第一位（保证 22 人双数开赛）
- 14:00 定时检查：名单恰好 23 人时，最后报名的非队长自动转候补首位并收到通知
- 14:00 后报名一律进候补，由队长/管理员审核补入；自动递补同时暂停
- 比赛页时间线与报名规则弹窗同步更新

### 选人体验
- 选人期间页面每 4 秒自动刷新，对方队长选的人几秒内同步显示
- 选人撞车（同时选同一人）失败后自动刷新名单，弹窗只显示简明原因，不再出现一整屏报错代码

### 其他
- 满员不再锁死报名：名额满时仍可加入候补排队（后端已提前生效）
- 「已就绪」状态下仍可请假，空位自动递补
- 新注册用户默认「未激活」，由管理员手动分配次卡/年卡
- 比赛人数恢复可配置（新建/编辑比赛、系统设置默认人数）

## v1.1.3 — 2026-07-29

- **管理后台实时看板**：dashboard 顶部显示下一场比赛的 已报 N/max · 候补 · 请假，点击直达比赛页——替代逐条报名推送
- **管理员通知管线（待激活）**：请假/退出、满员、会员申请三类事件会给所有管理员发订阅消息；管理端常用操作会静默积攒发送额度。需在 mp.weixin.qq.com 选好模板并填入模板 ID 后生效，未配置前完全静默、不影响使用
- **已进名单的朋友可移除**：带人者/管理员在名单行可直接移除不来的朋友，空位自动按优先级递补（此前只有候补中的朋友能移除）

## v1.1.2 — 2026-07-27

### 新功能
- **🎖️ 队长榜**：榜单页新增第三个 tab，按场均积分排名（胜 3 / 平 1 / 负 0），同分比场均净胜球（负/平记 0）；每行显示出场数、胜平负战绩。数据自动来源于赛后比分记录，无需额外录入
- **进球 / 助攻手动保存**：加减按钮先改本地数字，点「保存修改」一次性提交，页面不再每点一下刷新闪烁；有未保存改动时有明显提示
- **成员管理筛选**：新增 非年卡（默认）/ 年卡 / 全部 筛选，列表按注册时间从新到旧排序，最新进队、待分配身份的人排最前
- **位置必选**：完善资料和修改资料必须至少选 1 个擅长位置（前端 + 服务端双重校验）；带朋友也必须为朋友选 1-3 个位置，名单和选人界面能看到朋友的位置
- **R2 后请假提醒**：进入 R2 后请假，确认弹窗和成功提示都会提醒去微信群里告知，方便队友补位
- **自由选人**：取消蛇形轮次限制，两位队长随时可选任何未分配球员，先到先得（同时选同一人只有先点的成功）；选完自动进入已就绪

### 修复
- **新用户引导三层修复**（此前新人从分享链接进来会卡在"报名已关闭"、中途退出再进变空白页）：
  - 冷启动跳转引导页失败自动重试
  - 热启动（退出后短时间再进）重新检查引导状态，不再停留在无身份的空白页
  - 比赛页对未注册访客显示「完善资料，立即报名 →」按钮，填完自动跳回原比赛
- **会员身份实时生效**：管理员改完年卡/次卡，对方刷新比赛页即生效，不再需要重启小程序
- 带朋友弹窗点输入框会直接关闭（事件穿透），四个弹窗全部修复
- "已报名 / 候补"卡片文字被按钮挤压成一字一行
- 队长选人按钮话术：「→ 选人中」改为「开始选人」等动作动词，不再误解为当前阶段

### 数据 / 运维（云端已生效，与发版无关）
- 全部云函数已部署至最新
- 无位置的存量用户已统一补为 GK

## v1.1.1 — 2026-07-26

### 球员端新功能
- **🏆 射手榜 / 助攻榜**：首页新增入口，按赛季累计进球、助攻排名
- **比分记录**：比赛结束后可在详情页和往期列表查看比分
- **带朋友候补**：年卡会员完成自己报名后，可帮朋友加入候补（每人最多 2 位）；朋友递补成功会通知带人者；带人者退出后朋友转为普通候补
- **候补优先级**：年卡本人 > 年卡带的朋友 > 次卡，同级按先来后到；候补列表按真实递补顺序显示
- **次卡 R1 可候补**：R1 年卡优先轮里，次卡会员可以先排队，R2 开放时自动按优先级递补
- **报名规则 & 阶段时间**：比赛详情页新增「报名规则」说明，并显示 R2 开放时间（开球前 8 小时）和名单锁定时间（开球前 1 小时）
- **会员自助申请**：在「我的」页申请年卡/次卡（需填真实姓名），管理员审批后生效
- **禁赛提示**：被禁赛的球员会直接看到剩余场次，不再是点了报名才报错

### 管理端新功能
- **会员申请审批**：管理后台新增「会员申请」页，待审批数量在后台入口和「我的」页红点提示
- **候补直接提名单**：候补列表每行「↑ 进名单」按钮，无视顺序直接补人
- **比赛可编辑**：地点 / 日期 / 时间 / 人数创建后可改，不用再取消重建；新建比赛支持选择开球时间（按美东时间）
- **比分与数据录入**：就绪/已结束的比赛可录比分、逐人记录进球和助攻
- **操作报错透传**：失败时显示具体原因（如"需先设置队长"），不再只有"操作失败"
- **出勤统计修正**：超过 100 条记录不再被截断，日期范围计算修正

### 修复
- 从分享链接冷启动时误显示「报名已关闭」/ 管理页被弹回「无权限」
- 候补确认倒计时到期后永远不释放名额（同时卡住候补者和名额）
- 队长选人顺序错误（此前 A 队长连选两人，现为 A-B-B-A 蛇形）并防止双击连选
- 禁赛场次永不递减（现在每完成一场比赛自动减 1）
- 重复标记「已结束」导致出勤重复累计
- 报名满员瞬间并发导致超员
- 已取消的比赛在列表中消失
- 改名后旧名字仍显示在名单/战术板
- 多处加载失败白屏改为可重试
- 安全加固：管理员提权、配置重置、伪造通知三个漏洞封堵

### 待办 / 已知事项
- 管理员微信推送（会员申请提醒）需配置订阅消息模板 ID 后生效，当前仅小程序内红点
- 缴费管理功能整条链路暂未启用（按决定跳过）
